# Entradas de ejecución

Esta carpeta contiene únicamente las entradas numéricas usadas por los
ejemplos MATLAB y sus metadatos. El CAD fuente original no se publica.
Los datos derivan de la geometría aportada al proyecto y su procedencia queda
registrada mediante SHA-256. Las propiedades de materiales de literatura se
definen en `matlab/+fem3d/material_reference.m`, no en la malla.

Consultar [formatos, ejes, auditoría y preprocesamiento](../docs/data-and-preprocessing.md).
El [manifiesto](manifest.json) permite comprobar integridad de las copias.
Las referencias bibliográficas son atribuciones; el repositorio no redistribuye
artículos ni conjuntos de datos externos completos.
