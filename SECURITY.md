# Reportar problemas

Para un problema numérico o de reproducibilidad, abrir un issue con un caso
mínimo. Evitar adjuntar credenciales, información personal o CAD restringidos.
Para una vulnerabilidad que permita ejecutar código o exponer información,
usar el canal privado de seguridad de GitHub cuando esté disponible; en otro
caso contactar a los mantenedores de MC-Andes antes de publicar los detalles.

Los scripts de preprocesamiento leen archivos CAD y requieren dependencias
externas. Ejecutarlos en un entorno separado. El solver MATLAB no descarga
dependencias ni necesita claves para ejecutar los ejemplos incluidos.
